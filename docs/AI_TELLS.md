# AI tells: what the detector looks for

Each tell has a weight. The sum is the site's "AI-look score" (0-100).

| Area | Tell |
|---|---|
| Color | Purple/indigo-to-blue gradients; gradient text; glowing blurred blobs; default Tailwind palette untouched |
| Type | Inter/system font only; one weight ramp; all headings the same size jump; tight gray body text |
| Layout | Centered hero + badge pill + two buttons; uniform 3-column feature grid; alternating image/text rows with identical rhythm; everything max-w-6xl centered |
| Components | Same rounded-2xl card with soft shadow everywhere; emoji or generic Lucide icons as feature icons; pill badges ("New", "Beta") |
| Copy | "Elevate", "seamless", "unlock", "revolutionize"; three-word taglines; fake testimonials/stats |
| Imagery | Placeholder gradients instead of real imagery; generic abstract SVG backgrounds |
| Motion | Fade-up on every section; hover scale on every card |
